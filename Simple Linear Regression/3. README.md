# 🧬 Tumor Growth Rate Prediction — Simple Linear Regression

A machine learning model that predicts **tumor growth rate (mm/mo)** based on **PSA (Prostate-Specific Antigen) level (ng/mL)** using Simple Linear Regression, built with Python and scikit-learn.

---

## 📌 Overview

This project trains a Simple Linear Regression model on a Tumor Growth Rate Prediction Dataset to learn the linear relationship between PSA levels and tumor growth rates. The model achieves an exceptional R² score of **0.9945**, indicating that PSA Level is a highly reliable predictor of Tumor Growth Rate.

## 🔬 Model Details

| Property | Value |
|---|---|
| **Algorithm** | Simple Linear Regression |
| **Library** | `scikit-learn` — `LinearRegression` |
| **Coefficient (W / slope)** | `0.08520674` |
| **Intercept (B / bias)** | `2.6633265992077084` |
| **R² Score (Accuracy)** | `0.9945` (99.45%) |

### Linear Regression Formula

```
Tumor Growth Rate = W × PSA Level + B
Tumor Growth Rate = 0.08520674 × PSA Level + 2.6633265992077084
```

### Example Prediction

For a PSA Level of **23.83**:

```
Tumor Growth Rate = 0.08520674 × 23.83 + 2.6633265992077084
                 ≈ 4.6938
```

Model output: `array([4.69380331])`  ✅ Verified manually.

## 🧪 Code Walkthrough

### 1. Import Libraries
```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn import linear_model
```

### 2. Load Dataset
```python
df = pd.read_excel("Tumor Growth Rate Prediction Dataset.xlsx")
```

### 3. Visualize Data
```python
plt.scatter(df['PSA Level'], df['Tumor Growth Rate'])
plt.xlabel('PSA Level', color="Blue")
plt.ylabel('Tumor Growth Rate', color="Blue")
plt.title('Tumor Growth Rate Prediction Dataset')
plt.plot(np.unique(df['PSA Level']),
         np.poly1d(np.polyfit(df['PSA Level'], df['Tumor Growth Rate'], 1))
         (np.unique(df['PSA Level'])), color='red')
plt.show()
```

### 4. Train the Model
```python
lr_tgr = linear_model.LinearRegression()
lr_tgr.fit(df[['PSA Level']], df['Tumor Growth Rate'])
```

### 5. Predict
```python
lr_tgr.predict([[23.83]])
# Output: array([4.69380331])
```

### 6. Evaluate
```python
R2_Score = lr_tgr.score(df[['PSA Level']], df['Tumor Growth Rate'])
print(R2_Score)
# Output: 0.9945312238000856
```

## 📉 Model Performance

The R² (R-squared) score of **0.9945** means the model explains **99.45%** of the variance in tumor growth rate from PSA level alone — indicating an extremely strong linear relationship between the two variables.
