## Overview

BMI (Body Mass Index) is a widely used health metric that correlates body weight relative to height. This project implements a **Multivariate Linear Regression** model to learn the relationship between height, weight, and BMI from a labeled dataset, and then use that relationship to make accurate predictions on unseen inputs.

This project covers the end-to-end ML workflow:

- Data loading and inspection
- Model training
- Prediction
- Manual formula verification
- Accuracy evaluation via R² Score

---

## How It Works

The model takes two input features:

| Feature  | Description              | Example Value  |
|----------|--------------------------|----------------|
| `Height` | Height of the individual | `3.654`        |
| `Weight` | Weight of the individual | `94.757575 kg` |

It outputs a single continuous value:

| Target | Description                      |
|--------|----------------------------------|
| `BMI`  | Predicted Body Mass Index value  |

## Dataset

- **File:** `Weight-BMI Predictive Dataset (50 Samples).xlsx`
- **Samples:** 50 labeled records
- **Format:** Excel (`.xlsx`)
- **Columns:** `Height`, `Weight`, `BMI`

The dataset was loaded using `pandas.read_excel()` and passed directly into the model for training.

## Model Architecture

**Algorithm:** Multivariate Linear Regression (`sklearn.linear_model.LinearRegression`)

The model is trained on two independent variables (`Height`, `Weight`) to predict one dependent variable (`BMI`).

```python
from sklearn import linear_model

model = linear_model.LinearRegression()
model.fit(df[['Height', 'Weight']], df['BMI'])
```

After training, the model exposes:

- **Coefficients (`coef_`)** — the learned weight for each feature
- **Intercept (`intercept_`)** — the learned bias term

---

## Mathematical Formula

The trained model uses the standard linear regression equation:

```
BMI = W₁ × Height + W₂ × Weight + B
```

With the learned parameters from training:

```
BMI = (-8.22751629 × Height) + (0.33593944 × Weight) + 24.49166546
```

**Manual verification example:**

```python
Height = 3.654
Weight = 94.757575

BMI = (-8.22751629 × 3.654) + (0.33593944 × 94.757575) + 24.49166546 = 26.26112761937261
    ≈ predicted value
```

This manual calculation was cross-verified against the model's `.predict()` output to confirm correctness.

## Results

| Metric     | Value                |
|------------|----------------------|
| **R² Score** | 99.98% Evaluated via `model.score()` |
| **Coefficient (Height)** | `-8.22751629` |
| **Coefficient (Weight)** | `0.33593944`  |
| **Intercept (Bias)**     | `24.49166546` |

The **R² (R-squared) Score** measures the proportion of variance in BMI explained by the model. A score closer to `1.0` indicates a stronger fit.
